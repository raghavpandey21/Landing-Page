# 🌐 Landing Page Website

A simple and responsive **Landing Page** created using **HTML and CSS**.  
This project is designed for beginners to practice webpage layout, alignment,
and styling using modern CSS techniques.

---

## 🚀 Features

- Clean and modern design
- Header with navigation menu
- Hero section with call-to-action button
- Features section with columns
- About section
- Footer with copyright
- Well-aligned layout using Flexbox
- Beginner-friendly structure

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox, Box Model, Layout Styling)
